# 🌐 Personal Data Engineering & AI Portfolio Website

[![Live Portfolio](https://img.shields.io/badge/Live_Portfolio-ivaneklumberjack888.github.io-10b981?style=for-the-badge&logo=googlechrome&logoColor=white)](https://ivaneklumberjack888.github.io/)

Personal developer portfolio website for **Ivo Doležal** — Data Engineer & AI Specialist based in Brno, Czech Republic.

## 🚀 Features

- **Modern Glassmorphism Aesthetic**: Dark-themed UI with emerald accents, glowing cards, and smooth CSS transitions.
- **Dynamic Skills & Progress**: Categorized breakdown of Azure Integration, Data Platform, AI & Automation, and Software Engineering skills.
- **Featured Case Studies**: Interactive project showcases (AIVOS, Azure Integration, Power BI, Python Automation).
- **Responsive Layout**: Fully optimized for mobile, tablet, and desktop viewports.

## 🛠️ Built With

- **HTML5**: Semantic markup
- **Vanilla CSS**: Custom design system, CSS variables, glassmorphism filters, responsive grid layout
- **JavaScript (ES6+)**: Typing animations, dynamic skill progress counters, interactive project cards
- **GitHub Pages**: Automated deployment & hosting
